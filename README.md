## 🌐 Live Web Address

**[https://sudoshea.github.io](https://sudoshea.github.io)**

---

## 🛠️ Stack & Standards

* **Structure:** Clean, semantic, zero-dependency HTML5 & CSS3 featuring CSS custom properties and embedded inline SVG assets.
* **CI/CD:** Automated HTML static analysis via `HTMLHint` running under Node.js 24 and automated GitHub Pages deployment.
* **Hosting:** GitHub Pages.

sudoshea.github.io/
